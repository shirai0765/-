# SHIBUYA CAPITAL

渋谷のカフェから企業グループを育てる、ブラウザー向け3D経営ゲームの初期版です。旧カードゲームを置き換えています。

[ブラウザーで遊ぶ](https://shirai0765.github.io/-/)（**0.4.3 公開済み**）。公開サイトで新会社・出店・実測街への切替・週次保存と再読み込みを確認しました。開発用コードは `game-source` ブランチ、`main` はビルド済み公開サイトです。更新手順は [公開手順](docs/deployment.md) を参照してください。

## 開発・実行

Node.js 22.12以上（この環境では24）を使用します。

```sh
npm ci
npm run dev
```

Viteの開発サーバーを起動します。配布用ファイルは `npm run build` で `dist/` に生成し、`npm run preview` で確認できます。保存はHTTPSまたはローカル実行が必要です。`index.html` の直接ダブルクリックには対応しません。

```sh
npm test                  # 経営・市場・契約・保存・長期進行
npm run test:browser      # 開発サーバー起動中。Python Playwright + Chromiumが必要
npm run test:design       # 3テーマ・フォント・画面切替の検証
python3 scripts/smoke-managed-weeks.py # 連続営業の週次保存・中断・再開
npm run balance           # 複数戦略・32シードの比較結果を更新
npm run package:windows   # 検証済み公式Electronを使うWindows x64 ZIPの作成
```

クラウドでは `/workspace/-` の既存チェックアウトを使用します。ユーザーが要求しない限り追加のGit worktreeを作る必要はありません。

## 0.4.3で追加した範囲

経営画面の中で「ゲーム街」と「実測の渋谷」を切り替えられるようにしました。実測街ではセンター街・道玄坂・宮下・桜丘の各1地点、計4地点の屋上にゲーム内の目印を重ね、同じ会社の出店・店舗運営・物件保有へつなぎます。目印は未出店／店舗のみ／物件のみ／両方の状態と店名を表示します。実在建物の取得や実際の募集物件を表すものではありません。

経営対象は引き続き全32区画です。状態・地区で絞れる一覧から全件を選択でき、実測未対応の28区画は同じ区画のゲーム街表示へ移ります。財務で調達案を比較した後も、元の区画・出店形態と編集した資金計画へ戻れます。地図の切替や選択だけでは現金・週・所有・保存内容を変更しません。

PLATEAUの元建物データ、ゲームの立地・需要・距離・経済計算と保存形式は維持しています。実測への接続は屋上の目印までで、**カフェの外壁・入口・内装や改装後の外観を実測建物へ配置する部分は未実装**です。従来のカフェ近景と沿線開発の外観はゲーム街で確認できます。統合版の写真品質は軽量1024／高精細2048、独立ビューアは原寸も選択できます。

ビルドと226ユニットテスト（25ファイル）が成功し、全32区画・四所有状態・財務往復のDOM検証も確認しました。都市単体では独立ビューア9項目・controller6項目の実GPU検証と、4地点の実クリックが成功。元105アセットと0.4.2の形状・頂点接続・UV・配置の一致も確認しています。DOM検証の3D置換とは別に、Firefox/Mesaで実rendererを使ったApp統合GPU検証5項目も成功しました。読込中の選択、2店舗の週決算・保存、地図切替時の破棄を確認しています。

HTTP503・WebGL生成失敗時の経営継続2項目と、本番CSP下の9項目も成功し、旧0.3.2セーブの読込結果が完全一致しました。正式オフライン版の9項目も成功しました。公開サイトのFirefox検証7項目も成功し、JavaScriptエラー・通信失敗は0件です。詳しくは [開発進捗](docs/progress.md)、[独立レビュー](docs/design/real-city-integration-review-v043.md) を参照してください。

## 継続して遊べる経営機能

- 渋谷を参考にした3D街区。32の出店候補、駅・交差点・商業ビル・公園、需要と所有物件の表示。
- カフェの立地・価格・品質・人員・広告・設備投資。店長へ予算内の運営調整を委任できます。
- 0.3.2では同じ場所の3形態を、支払後資金・全社利益・既存店への影響で比較。出店時の予測と初決算を最近40件まで保存し、次の運営や出店へつなげます。
- 0.4.0では自己資金・借入・IPO/増資の現金、返済、持分を比較。市場の買収候補は最大3件を並べ、費用・利益幅・稼働時期を検討できます。
- 0.4.1では出店・買収・沿線計画の対象と必要額を財務へ渡し、入力を保ったまま元の案へ戻れます。主要な金額と警告を先に示し、細かな内訳は展開して確認できます。
- 0.4.2では店舗の需要・対応上限・利益・満足度を同じ週の予測として確認できます。店長の実効設定と費用も表示し、今の店の制約を判断できます。株式の分割売買で端数利益が生まれる不具合も修正しました。
- 実測渋谷の独立ビューアは写真の精細さを3段階で選べます。既定は軽量表示で、近景の細部を見たい場合は原寸へ切り替えられます。建物の形状・範囲は変えません。
- 初決算は実際の店舗利益と来店者を先に表示。「店の様子を見る」で対象店舗の近景へ移動できます。上場直後には調達額・持分の変化と次の投資への入口を表示します。
- 明るい昼景と3つの画面テーマ。Manrope / Noto Sans JPを同梱。所有店舗の名前・営業スタイル・設備改良が外観に反映されます。
- 0.3.1では109型ビルとプレミアムカフェをBlenderで仕上げたGLBへ更新。窓枠・金属・木部の角、ガラス、家具寸法を調整。ゲームでは108の架空名とプレイヤーの店名を使い、同じカフェのデータを共有して配置します。
- 成長戦略画面で創業・チェーン・不動産・IPO・グループ・鉄道への目標と資金余力を確認。
- 4地区×3段階の街区開発。集客重視・賃貸重視の計画を選び、投資・工期・維持費を管理。完成すると街の照明・植栽・テラスなども変化します。
- 上場後は保有地区の駅周辺で、商業広場または賃貸拠点への共同投資も可能。店舗の余力と外部賃貸の保有状況で効果が変わり、建設中・完成・休止を3Dで確認できます。共同開発は任意です。
- 上場・全買収対象の取得・4地区の開発完了・黒字を最終目標として表示。達成後も会社の経営を継続できます。
- ボタンで1週ずつ決算。累計12週の黒字後は4週/13週の連続営業も選択でき、毎週保存して新提案・IPO機会・街区開発完了・破綻予測で停止。借入・返済・不動産取得/改修・事業買収・IPO・増資・持株比率・配当。
- プライム40、スタンダード30、グロース25、REIT5の100銘柄。1株からの売買、条件検索、保有損益。
- 市場100件の友好的取得。有料調査、独立運営／グループ統合、引継ぎ期間の費用、稼働後の事業利益。保有株は時価で充当され、取得後は通常の株式売買を終了します。
- 営業提案の調査・契約・見送り・解約。初回2提案に加え、企業規模や週に応じた10種類の提案。導入待ち期間、費用、後から判明する実績、不動産の営業案件。
- 新しいカフェ向け提案は観測済みの店舗数・客数・赤字店舗数を考慮し、契約期間全体の純収支幅を表示。調査で将来の結果が確定するわけではなく、旧契約の条件は維持します。
- 毎週の自動保存、12世代の履歴、JSON書き出し/読み込み、破損時の履歴復元、複数タブの上書き防止。

借入が残る週に「営業利益 − 利息」がゼロ以下になるとゲームオーバーです。出店費と借入元本の返済は、この利益とは分けて資金繰りに反映します。現金不足による終了もあります。週終了前の予測で確認できます。

## データ・モデルの扱い

100銘柄の開始価格は取得日付きの実株価参照値です。現在の収録値は2026年10月2〜6日の各銘柄の最終取引時点で、同時刻ではありません。開始後はゲーム内の仮想価格になり、実際の株式注文やライブ更新は行いません。配当率・リスク・経営収益はゲーム用の設定です。出典と市場区分照合は [docs/sources.md](docs/sources.md)、更新手順は `scripts/research-market.py` にあります。

従来の「ゲーム街」は実在建築を参考に作った圧縮街区です。109は公式写真・接写を照合し、円筒・吹き抜け・ガラス昇降塔・入口トラス・屋上を再構築しました。寸法と隠れた背面は推定です。写真出典は [docs/photo-references.md](docs/photo-references.md)。

別画面の `real-shibuya.html` では、公式PLATEAUの渋谷区2025年度LOD2建物20タイルと国土地理院の空中写真を表示します。建物の配置・外形・テクスチャは実データです。地面は平面近似です。0.4.3では経営画面内にも上記4地点の対応付けを加えています。独立ビューアも引き続き利用できます。全32区画を実測座標へ置き換えるものではありません。起動画面または設定の「実際の渋谷を3Dで見る」から開けます。詳細は [docs/real-city.md](docs/real-city.md)。 単一ファイルのオフライン版は `node scripts/package-real-city.mjs` で生成できます。建物20タイル・ズーム18の航空写真72タイル・Dracoデコーダーを含め正式0.4.3版は83,272,262バイト（約83.3MB）。HTMLをダウンロードして開くだけで、外部アセットへの通信は不要です。建物の明るさは画面のスライダーで調整できます。

開発サーバー起動中の `npm run model:export` でGLBを書き出せます。`npm run model:viewer` で経営マップの建築スタディを回転・拡大できる、外部通信不要の単体HTMLを生成できます。ゲーム本体と違い、モデルビューアは全データを1ファイルに同梱します。管理ブラウザーのローカルファイル制限は無効化せず、同一HTMLを内部HTTPで動作確認しています。

実測ビューアの単体HTMLは `npm run model:real-viewer` で生成します。建物・空中写真・Dracoデコーダーを同梱し、外部通信なしで描画できます。

`blender --background --threads 4 --python scripts/prepare-blender.py` で編集用 `.blend` を生成します。既定出力先は `/workspace/shared/shibuya-artifacts/` です。

Blenderで仕上げる工程は `scripts/polish-109.py` と `scripts/polish-cafe.py`、ゲームへの読込・破棄の仕様は [docs/loaded-assets.md](docs/loaded-assets.md) を参照してください。編集用モデルと、ゲーム用の軽量なガラス・架空文字を使うモデルを分けています。この3D更新は経営データと保存形式を変更しません。0.3.2の出店記録は、旧セーブを読み込める任意項目として追加しています。

街の制作と並行して3担当で検討した成長体験・経営の分岐・進行の方針は [docs/design/README.md](docs/design/README.md)。出店比較の操作検証は [docs/opening-playtest.md](docs/opening-playtest.md) を参照してください。

Coffee Inc / 2・ほしの島のにゃんこ・桃鉄と、桜井政博さんのゲーム制作資料の調査は [docs/research/game-reward-study.md](docs/research/game-reward-study.md)。公式説明・本人の公開発言・レビュー・第三者要約を区別し、読み取った原則と今回の実装を結び付けています。公式YouTube本編と字幕は環境の403で取得できず、視聴済みとは扱いません。

## 初期版の限界

- 最新の目標は約30時間でのキャンペーン完遂です。人による30時間のプレイ検証は未実施。0.4.0は2シード×沿線投資3方針の全6経路で、上場・市場100件の稼働・既存8社買収・4地区全工程・直近決算と予測の黒字まで922〜1,010週で到達しました。ゲーム内の週数は実際のプレイ時間ではありません。設計は [docs/campaign-30h.md](docs/campaign-30h.md)、最新結果は [docs/campaign-v4.md](docs/campaign-v4.md) を参照してください。
- 市場100銘柄（95社・5REIT資産）の友好的取得に対応。事業価値と収益はゲーム用に調整した係数です。実在企業の時価総額・業績を示すものではありません。
- 店舗需要や営業提案の係数は仮定であり、100社の開示資料から推定した経営モデルではありません。
- 鉄道は買収可能な事業資産と駅周辺への共同投資として扱います。共同投資だけで鉄道会社を所有するわけではありません。自由な路線敷設、海外の3D都市、地区追加、道路や敷地形状の自由な再開発は未実装です。
- 詳細な週次グラフは直近520週を保持します。会社の現在状態、累計実績、契約は継続します。
- Windows ZIPは生成・同梱ファイル検証済みですが、公開ダウンロードは現在未提供です。Windows実機での起動とRyzen 5 PRO上の性能も未検証です。ブラウザー版は上のURLで遊べます。

市場企業の買収は [docs/market-acquisitions.md](docs/market-acquisitions.md)、保存の仕様は [docs/saves.md](docs/saves.md)、経営の計算は [docs/economy.md](docs/economy.md)、営業案件は [docs/deals.md](docs/deals.md)、Windows起動は [docs/windows.md](docs/windows.md) を参照してください。
