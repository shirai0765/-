# 開発担当と外部担当への引継ぎ

更新：2026-10-07。ゲームの開発ソースは `game-source`、公開専用の `main` はビルド済みサイトです。**ソースをmainへpushしないでください。**

現在の公開版は [0.7.0](https://shirai0765.github.io/-/?v=0.7.0)。次の作業は、街の密度と出店の選択肢を増やす0.8.0です。ブラウザー内のセーブは個人の端末にあり、この文書からは見えません。

## このクラウドの担当

6つのサブ担当はGPT-6.1 Sol・極高。親が統合・リリースを持ち、街側の副統括が座標とファイルの境界を調整します。同時実行は親を含め7体。GPUブラウザーは1本、全体テスト・本番ビルド・公開は親だけが実行します。

| 担当 | 作業 | 専有する範囲 |
|---|---|---|
| 親 | 統合、保存互換の確認、公開 | App、版番号、配布・公開記録 |
| 街側の副統括 | 依存関係、座標契約、独立レビュー | `docs/design/city-expansion-v080.md` |
| 街 | 外周の景観・道路・カメラ・目印 | `district.ts`、`CityView.tsx`、街の配置・目印 |
| 経済・物件 | 各地区6件、計24件の新しい候補が目安 | `neighborhoodsV080.ts`、専用テスト |
| 建物外観 | 雑居ビル・オフィス・集合住宅の違い、描画負荷 | `art.ts`、新しい外観モジュール |
| 操作 | 候補が増えても選びやすい物件一覧 | `SiteBrowser.tsx`、専用CSS・テスト |
| 品質 | 既存保存・配置・性能・実ブラウザー回帰 | 合意した専用テスト、検証記録 |

0.7.0の公開検査が終わるまでは0.8.0の実装ファイルを凍結し、各担当は読取・設計・契約調整を進めます。解除は親が担当へ通知します。既存48物件のID・位置・経済値と109・実測写真モデルを保持します。背景の建物数だけでなく、選べる物件も増やします。72件は配置と動作確認後に確定する目標です。

## ドットなど、別タスクから参加する担当へ

このホストには、別のCloud Codexタブを作成したり、既存タブへ直接指示を送ったりする操作がありません。以下は共有可能な作業指示であり、外部担当への送信・着手を確認した記録ではありません。

まずこの文書と [最新の仕様と検証](interaction-v070.md) を読み、`game-source` の最新版を基点に独立したブランチを作成してください。親の編集中ファイルと同じ場所を変更せず、完了時はコミットまたはPRと短い検証報告で受け渡してください。公開ブランチへ直接反映しないでください。

外部担当に分離できる仕事は次の2件です。

1. **街の模型用の追加資料・独立アセット**：渋谷の雑居ビル、路面の飲食ビル、集合住宅を各1種以上。参照した実写真のURL・出典・取得条件を記録し、既存の109やPLATEAUデータを置き換えない。モデルを作る場合は単位m、+Yが上、接地面Y=0、原点を建物中央、外壁の正面方向を明記する。GLB、サムネイル、寸法、頂点／三角形／材質／テクスチャ容量を添え、まず軽量な1棟をレビュー可能にする。保存先は `public/models/external-v080/`、生成スクリプトは `scripts/external-v080/`、資料は `docs/external/dot/` に限定する。街への配置と既存レンダラーの変更は親側が統合する。
2. **公開画面の初見操作レビュー**：新会社→物件選択→開業→一週終了→ニュース→銀行の金額・期間選択→審査、の迷った箇所を記録する。利用端末・ブラウザー・版・再現手順を添える。既存プレイヤーの保存を削除せず、検証用ブラウザープロファイルを使う。コード修正は行わず、`docs/external/dot/` に報告する。実機Safariで音を聞けた場合は、実音声を聞いた範囲と操作だけを明記する。

他の担当の作業を上書きするforce pushや、本番の設定変更は不要です。外部タスクのURL・ブランチ・成果物が共有されたら、親がこの担当表へ追加して重複を避けます。
