### 完遂判定の統一と旧セーブへの影響

0.4では `src/sim/campaign.ts` の `getCampaignCompletion` を画面と戦略スクリプトで共有し、**直近の保存済み決算と今週予測の両方が黒字**であることを要求する。従来の戦略検証はこの条件だったが、旧UIには直近決算を確認しない不一致があった。

新しい沿線投資を必須にした変更ではない。一方、このUI不具合修正によって、直近決算が赤字またはゼロなのに予測だけで完遂表示されていた旧セーブは、表示上未完へ戻る場合がある。保存された取引・過去利益・取得済み資産は改変しない。借入があり利息後の週利益がゼロ以下なら倒産するルールも維持する。

922〜1,010はゲーム週、323〜329は操作回数で、人間の活動時間や意味のある判断の観察数ではない。30時間の通し実プレイ、初心者による判断の理解、長期の楽しさは未検証である。

### まだ残る体験上の課題

- 完遂不能な資金・信用・工期の阻害要因はこの4試行では見つかりませんでした。
- 一方、設備投資・買収・開発着工がない区間が**92〜172週**残ります。全地区が136〜186週で完成し、大型鉄道の取得を待つ後半に空白があります。営業提案の調査は続きますが、長期の体験密度を十分にしたとは言えません。
- 開発は12の追加投資判断を成立させました。現実時間を強制的に遅くせず30時間の密度を目指すには、買収後統合や沿線の選択など追加の内容と人間による観察が必要です。資産価格を上げて待たせるだけで30時間に調整してはいけません。
- 自動進行は開発工程が完成した週を保存してから止まります。回帰テストでは通常営業で得た資金で工事を始め、各週を実際の保存エンベロープで往復し、完成状態の保存が停止通知より前に行われることを確認しました。

## 旧検証：開発追加前の全8社取得

以下は開発を含めなかった8シードの履歴で、現在のスクリプトとは終了条件・投資戦略が異なります。

### 当時の結果

初期資金1,200万円から、実際の公開アクションだけで、6店舗の店長委任・IPO・不動産・全8社の買収・鉄道2社まで到達できました。シード1〜8の8試行は全て完走しました。最大の鉄道会社取得は317〜417週（約6.1〜8.0ゲーム内年）です。これは旧目標時点の経営経路確認であり、最新目標の30時間の遊びの密度を保証する結果ではありません。

途中で「物件購入→4回改修→即売却」により同じ週に購入額の6.8%を無限に増やせる問題を発見し、エンジン担当へ報告しました。担当の修正後に、実際の事業で稼いだ資金を使う分岐で再確認しました。3,000万円の物件の同操作は660万円の損失となり、この増殖経路は閉じています。キャンペーン本体は売却分岐の利益を一切利用していません。

### 当時の実行方法

```sh
CAMPAIGN_SEEDS=8 CAMPAIGN_WEEKS=2000 npx vite-node scripts/campaign-report.ts
```

1行1シードのJSONを出力します。各行には投資履歴、年次チェックポイント、到達週、最大資産減少率、最長投資間隔、セーブ往復一致、改修転売の検証結果を含みます。

- 全て `createGame`、`applyAction`、`advanceWeek` を使用。現金、信用、店舗レベル、契約条件の直接書換えはしません。
- 株式の将来価格・隠れた将来結果を先読みせず、その週の公開予測で比較します。借入と株式売買は使わず、営業利益・IPO・持分下限内の増資で賄います。
- 当初は立地の利回りを比較して3店舗まで開き、品質85以上・満足度85以上を候補に価格と人員を調整します。3店舗以降は店長へ委任し、最大6店舗までの追加店も委任後の全社利益で比較します。
- 4週ごとに投資を見直します。出店後120万円、設備投資後300万円、買収後500万円を残す範囲で、現在の追加利益／費用が高い案件を選びます。IPO後に物件を1つ保有します。
- 増資は現金3,500万円未満・創業者持分の条件を満たす場合だけです。これは保守的な戦略条件であり、最速クリア探索ではありません。
- システム営業提案は調査し、控えめな効果から計算した契約期間収支が正のものだけ契約します。
- 毎年の状態を保存検証し、最終状態はSHA-256付きJSONへ書き出した形式から完全一致で復元します。

## 体験上の限界と次の判断

1. **標準出店予測だけでは成長候補を取り逃します。** 当初のスクリプトは標準人員・店長なしの `evaluateSite` だけで判断したため全試行3店舗で止まりました。実際に店長を置く候補の全社利益を比較すると6店舗へ成長しました。プレイヤーにも、予定の店長・人員・品質を含む出店比較が役立ちます。予測関数の計算誤りではなく、前提設定の差です。
2. **後半は長く資金を貯める時間があります。** この戦略では96〜208週、設備投資や買収のない区間がありました。営業提案・週次確認は残りますが、世界進出や新規地区などの段階はありません。より積極的な増資・追加不動産投資で間隔を変えられるため、これは不可避の進行停止を示す数字ではありません。
3. **当時の買収目標は全8社でした。** 全8社を取得した後の新しい経営局面は、この過去検証の対象ではありません。取得額を引き延ばすだけでは長時間の手応えにはなりません。都市・事業ごとの制約、競争相手、更新される投資判断が必要です。
4. **8試行とも安定して同じ勝ち筋が成立しました。** 初心者の判断ミス・悪条件・借入リスクは別の検証です。この結果だけで難易度や戦略の多様性が十分とは言えません。
5. **実時間の長期プレイは未検証です。** 数百週の決定論的な計算とセーブ復元を検証しました。実ブラウザで30時間遊び続けた検証、全端末の保存永続性、クラウドバックアップの保証ではありません。
