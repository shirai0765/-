# 0.7.0：街と企業を育て切った記録

0.6.1の全画面レビュー・カフェ音・融資審査を保ち、序盤から全企業取得までの流れを6担当で監査しました。経済係数を引き伸ばす調整ではなく、実際に見つかった終点・保存・導線の不足を修正します。

## 達成は、その週の営業で確かめる

上場、既存8社と市場100事業の取得・引継ぎ、4地区の全工程の稼働をそろえたうえで、実際の週末決算が黒字、現金が非負、経営終了していなければ達成します。翌週の利益予測を条件にしません。最後の事業がまだ引継ぎ中だった週や、最後の取得以前の古い黒字で達成したことにもなりません。

最初の達成週・利益・決算後資金・累計来店者・店舗／物件数と対象事業数を、任意の `campaignAchievement` に一度だけ記録します。旧セーブに後付けの達成を推測して書き足しません。条件を満たした旧会社は次の実際の黒字決算で記録を得られます。保存version 1／envelope 1は維持します。

保存が成功してから専用の全画面で節目を知らせます。連続営業も、その保存を終えた週で一度止まります。同じ会社で経営を続けられ、メニューや成長戦略から達成記録を読み返せます。後の支出・物件売却・赤字・経営終了で過去の達成記録を書き換えません。達成後に現状の地区運営が止まった場合は、現在の不足と過去の達成を分けて表示します。

## 実績に基づく上場と、次の行動

上場の4条件のうち将来の基準利益判定を、直近の確定決算の黒字へ変えました。他の3条件は3店舗以上、累計12週の黒字、純資産2,000万円以上のままです。経営を終了した会社は上場できません。企業価値・借入枠・金利の計算は変えていません。

週末のニュースでは、今の会社が上場可能なら証券市場への入口を表示します。これは現在の判断機会で、過去のニュースに上場資格を埋め込むものではありません。店舗詳細から次の出店先へ進むコールバックの抜けも直しました。買収候補は未取得を最初に表示し、経営メニューから市場へ戻るたびに株式投資へ切り替わる動作をやめています。

## 同じ週の借入と返済

借入→もう一件借入→先の契約を返済→同額を再借入したとき、週・契約数・手元資金を使ったIDが既存契約と重複する不具合を修正しました。重複すると保存検証が拒否し、一件の返済で二件を取り除く場合がありました。新規契約だけ未使用の接尾辞を選び、既存契約のID、元本、金利、返済期間は変えません。

## 事業投資の経過がニュースに届く

既存の26週のグループ事業投資について、開始・進行・完了をその週の保存済み実績から掲載します。利益差はその週の通常運営との比較で、週次運営費込み・初回費用別。最終週の差を全26週の累計利益と呼びません。独立した他社の株価の動きと、自社グループの計画を分けて表示します。

独立した他社の出店や新製品開発を新しくシミュレーションした機能ではありません。ニュース用に架空の店舗増加を作ったり、新しい不明瞭な指数を増やしたりはしていません。保存されたニュースは取引・再表示・読込で変えません。
