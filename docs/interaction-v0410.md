# 0.4.10：店舗の見込みと提案で停止する選択

0.4.10公開・検証済みの記録です。今回の範囲は店舗設定の近くに出す今週の店舗利益見込みと、まとめて営業するときの任意の停止設定です。全体テスト・最終ビルド・ローカルの実ブラウザー検査、梱包、Pages公開・公開HTTP・公開実ブラウザー2導線は成功しました。

## 設定の近くで今週の店舗利益を読む

店舗管理の「商品・価格」「人員・店長」「広告・改装」の入力前に「店舗利益見込み／週」を一つの幅で表示します。幅は千円単位で外側へ丸めます。「実績は週末に確定。本部費・利息などは含みません。」と表示し、全社利益・現金増減・過去の実績と区別します。「見込みの理由」で既存の詳細を開けます。ホームと営業実績にはこの表示を追加せず、詳細も自動で開きません。

見込みには「第X週 · 反映済みの設定」を使い、店長がいる店には「からの店長案」を添えます。入力途中・無効・受け付けられなかった値を反映した表示にはしません。設定の変更理由を利益変化の原因として断定せず、実績は週末に確定します。価格や人員の正解を提示したり、次の変更を必須にしたりしません。

## 新しい営業提案で停止するか選ぶ

4週・13週の営業確認に「新しい営業提案で停止」を設けます。確認画面を開くたびにONへ戻る、その実行だけの選択です。会社保存や恒久設定には追加せず、1週終了には適用しません。

ONでは新しい提案が届いたときに従来どおり停止します。OFFではその理由で止めず、提案が確認前に期限切れになる可能性を説明します。自動契約や自動辞退は行いません。利益・現金の危険、IPOや成長・引継ぎ、保存失敗などの停止理由と週末の保存方針は維持します。まとめて進めるか、週ごとに判断するかを自分で選べます。
