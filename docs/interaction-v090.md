# 0.9.0：City Burstの営業画面と操作演出

ユーザーが選択した[見本B](design/concepts/city-burst-approved.png)を実装する更新です。濃紺・青・シアンの枠、黄色の主操作、大きな見出しと金額、渋谷とカフェの背景を営業結果・出店・銀行・市場・事業管理へ適用しました。生成した背景は画面装飾であり、実測渋谷の3Dスクリーンショットではありません。

## 表示と操作

営業後は街を隠す全画面で、確定した利益、現金増減、その決算時点の現金を表示します。初回は約1.18秒の短い演出、タップまたは「結果をすぐ表示」で即完了。同じ結果の再閲覧と動きの軽減設定では待たせません。赤字・収支均衡・経営終了に黒字のコイン演出を付けません。金額を演出の都合で増減させず、営業後の記録から表示します。

物件では立地と賃料、3形態、実際の開業費と支払後現金を表示します。選択だけでカメラを寄せず、利益の見込み値を再導入しません。銀行・証券市場・グループ経営・提案・開発・資金計画は対応する画面を揃えています。金額計算・契約条件・保存形式・乱数経路は変更しません。

日本語見出しはDela Gothic One、数字はBarlow Condensed Black Italicをローカル配信します。財布・人・店舗等はPhosphorの正規SVG25点です。原本URL・固定commit・SHA・MIT/OFLライセンスを同梱し、生成画像からアイコン文字を切り出していません。本文は可読性を保つ既存書体を使います。[共通仕様](design/city-burst-v090.md)。保存済みのnight設定でも、白いカード内は暗い文字・入力色に限定して読みやすくします。

## 音

一度のユーザー操作で開始する既存AudioContextへ、短いボタン音と実決算の結果音を追加しました。消音・一時停止・画面非表示・OS割込みに従い、後から音源が届いても過去の演出音を遅れて鳴らしません。外部制作のオリジナル「窓辺の午後」（84 BPM、45.714秒）を採用し、MP3とOGG代替版を同梱しました。独立検査で全形式の実デコード・音量・3回連結の境界・クリッピングを確認しました。音源はCC0、第三者の楽曲・録音サンプルを使わない独自合成です。別案の「坂道のネオン」も試聴ページに保持します。実ブラウザーの再生確認を続け、人による試聴を信号検査と同一視しません。店内音と効果音は既存の合成音を併用します。

## 最初の操作と街

[任天堂のマリオ開発者インタビュー2件](research/mario-onboarding-primary-v090.md)の一次本文を読み、現行の初回操作へ対応する4つの確認点を整理しました。開業後に選択物件が残ると案内まで消える条件を修正し、初決算まで既存の短い次の操作案内を保ちます。閉じる選択は維持し、必須の長い説明は増やしません。

Dotから受領した模型は実GLBと21枚の提出画像を独立レビューしました。4棟の小さい模型を既存の背景予約範囲へ配置し、大きい交差点商業ビル・テラス施設は素材として保持して専用配置を検討します。模型の自動縮小や旧109・実測渋谷・店舗区画・経済値の置換は行いません。
