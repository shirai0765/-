# 店長に任せて4週・13週進行

`runManagedWeeks` は通常の1週進行を順番に呼ぶ補助です。経済ルールを変更せず、各週の保存が完了するまで次へ進みません。店長の担当店舗は既存の自動調整を行い、出店・買収・借入・契約の採否はプレイヤーが決めます。

```ts
const result = await runManagedWeeks(game, 4, {
  commit: saveGame,
  onCommit: (saved, report) => { setGame(saved); },
  shouldCancel: () => cancelRequested.current,
});
setGame(result.state);
// stopReason は停止理由。nullなら指定した全週が完了。
```

UIでは進行中の重複実行や他の経営操作を無効にしてください。キャンセルは各週の間で確認します。すでに保存処理中の1週は完了してから止まるため、完了した週は失われません。各週の間でイベントループへ処理を戻し、画面更新と停止操作を受け付けます。

停止条件：

- 次週の予測で借入中の利益がゼロ以下、または週末現金がマイナス：その週を進めず、破綻する前に停止します。自動救済・自動借換えはありません。条件を直さず通常の1週終了を選ぶと、通常どおり破綻します。
- 新しくIPO条件を満たした、または新しい営業提案が利用可能になった：その週を保存して停止し、判断を戻します。開始時からある営業提案では止まりません。
- 保存失敗：失敗した週を採用せず、直前の保存成功状態と、その時点までの週報を返します。エラーは `stopReason` に入ります。
- キャンセル・ゲーム終了・計算異常：進行を停止し、完了済みの保存を維持します。

週報配列は実際に保存できた週だけです。保存後の表示コールバックが失敗した場合でも、戻り値は保存済みの新しい状態です。起きなかった週の利益を加算したり、停止時にまとめて保存したりはしません。

これは資金が貯まるまでの反復操作を減らす機能です。将来の利益を保証する仕組み、クラウド保存、ゲームに新たな長期目標を追加する機能ではありません。
