# データ出典とゲーム内の扱い

調査日：2026年10月7日（日本時間）。このゲームは架空の会社を経営するシミュレーションです。企業名はパロディ名、株価の初期値は以下の取得済み相場資料、プレイ開始後の価格変動・配当・業績は独立したゲーム内計算です。外部APIを起動時・プレイ中に呼びません。

## 分散した100銘柄：95社＋REIT5銘柄の実株価スナップショット

- 提供元：Yahoo Finance 公開 chart エンドポイント。例：[7203.T](https://query1.finance.yahoo.com/v8/finance/chart/7203.T?interval=1d&range=5d)。金融商品の取引情報をリアルタイム提供する機能ではありません。
- 100銘柄すべて取得成功。レスポンスの `meta.symbol`、`currency === JPY`、`instrumentType === EQUITY`、正の有限な `regularMarketPrice`、`regularMarketTime` を検証しています。
- 保存された提供元時刻：**2026-10-02 13:23:26〜2026-10-06 15:30:00 JST**（90銘柄は10月6日15:30、10銘柄はそれ以前。薄商い等で最終取引時刻が異なる可能性があり、全銘柄同時刻とは扱いません）。取得日は2026-10-07 JST。`priceDate` は取得日ではなく提供元の相場時刻です。「今の値段」「公式終値」と断定しません。
- 保存先：`src/data/stocks.ts`。各銘柄に `sourceUrl`、`priceDate`、`priceKind: 'market-reference'` を保存しています。過去の市場状況を表す固定参照値であり、以後の実際の株価に追従しません。
- **配当利回りと週次ボラティリティは実績値ではありません。** 業種別のゲーム用パラメータです。`dividendYield` は年率の小数（0.03 = 3%）、`volatility` は週次変動の小数です。`priceKind` は価格の由来だけを示します。配当・業績の実資料による校正は未完了です。
- 各パロディ名と実在企業の関係は `realName` と証券コードで確認できます。ゲーム内の評判、損益、倒産、配当等は実在企業への評価ではありません。

### 市場・規模・価格帯を分散した選定

| 区分 | 銘柄数 | 役割 |
| --- | ---: | --- |
| Prime | 40 | なじみのある20社に、JPXのTOPIX Small区分から20社を追加 |
| Standard | 30 | 幅広い業種と低価格株を含む投資先 |
| Growth | 25 | 成長型・無配型・値動きの大きい投資先 |
| REIT | 5 | オフィス・物流などの不動産投資口 |

旧マザーズに相当する現在の市場はGrowthです。市場区分は企業の大きさや安全性そのものではありません。時価総額を取得したとは表示していません。Primeで追加した20社だけはJPXの規模区分TOPIX Small 1/2を明示的に使っています。

有名な企業だけにはせず、30銘柄をアンカーとして固定し、残る70銘柄はJPX一覧から**市場別・業種別の層化抽出**を実施しました。アンカーはカフェ・鉄道・不動産等の認知しやすいPrime20社、低価格のStandard3社とGrowth2社、REIT5銘柄。残りは各市場のJPX33業種ごとに証券コードの `SHA256("shibuya-market-v1:" + code)` の昇順で並べ、業種名を昇順に巡回して必要件数を採用しました。Primeの抽出対象はTOPIX Small 1/2です。単純な有名企業ランキングでも、市場全体を再現する統計標本でもなく、遊びの選択肢を作る再現可能な抽出です。

全銘柄の証券コード・正式名称・市場・JPX業種・規模区分・資料日・選定方法は `docs/market-universe.json`、パロディ名との対応は `src/data/stocks.ts` に記録しています。アルファベット入り証券コードにも対応しています。

初期参考価格は**1株／1口あたり21.0〜143500.0円**。500円以下が15銘柄あります。ゲームは1株単位で購入でき、現実の単元株100株ルールは採用しません。安価な株は少額で始められるだけで安全とは限りません。低価格の5アンカーには高いゲーム内変動率と無配設定を用意しています。

投資性格 `profile` は実在企業の投資評価ではなくゲーム用です。安定型（defensive）、配当型（income）、成長型（growth）、景気敏感型（cyclical）、高変動型（speculative）で配当と変動率に差を付けています。配当型の年率中心値4.2%、成長・高変動型の無配設定等は設計値であり、実際の配当利回りを取得したものではありません。

### オフライン更新

```sh
python scripts/research-market.py --dry-run
python scripts/research-market.py
```

標準ライブラリのみ使用します。最大3リクエストを並列実行し、1リクエスト20秒でタイムアウト。7日より古い相場時刻・未来時刻・異なる通貨・異なる銘柄・不正価格は拒否します。必要なら `--codes 7203,9432` で対象を絞れます。ネットワークエラー時に再試行を繰り返さず、成功した銘柄のみ原子的に更新し、失敗した銘柄の既存データを保持します。一部失敗でも終了コード1を返します。配当・ボラティリティは更新しません。APIの仕様変更や提供停止時は更新できません。

更新に必要な接続先は `query1.finance.yahoo.com`。プロキシ・TLS検証を保持し、認証情報やネットワーク設定を変更しません。提供元の利用条件とデータ再利用条件は、ゲームを一般配布する前に確認が必要です。
