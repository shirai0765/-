# 0.8.0：街を広げ、物件を探しやすくする

0.7.0の経営・決算・達成を保ち、街の密度と出店の選択肢を増やしました。2026-10-07に公開した0.8.0の記録です。以後のUI・音声更新の検証結果とは分けて保持します。

## 街と出店先

4地区に6件ずつ、計24件の物件と15本の接続道路を追加しました。取引できる物件は48から72件、背景の景観表示候補は270から349棟になります。背景の数はデータ上の表示候補であり、画面内に同時に見える棟数ではありません。

外周の建物をオフィス・雑居ビル・集合住宅に分け、窓、バルコニー、地上階、屋上の違いを付けました。共有する形状と既存の色を使い、棟ごとのテクスチャを増やしません。109や実測写真モデル、既存の取引物件は保持します。

新物件にも人通り・購買力・賃料の違いがあります。静かな低賃料の場所で持帰り中心に始める選択と、人通りが多く賃料も高い場所へ設備・品質・人員を投資する選択を比べられます。利益は営業後の実績で確認します。立地の数値はゲーム用の設定で、東京の実測交通量ではありません。

## 探す・選ぶ・場所を見る

物件名と自社の店舗名を検索できます。「地区ごと」は実際に4地区順へまとめ、購入価格順も選べます。検索結果がない場合はその場で条件を解除できます。店舗・保有物件・出店候補のアイコンを分けました。

未開業の物件では、詳細の「街でこの建物を見る」を押した時だけ、その場所へ水平に移動します。角度・ズーム・高さを保ち、「街全体に戻る」から俯瞰へ戻れます。普通に物件を選ぶだけではカメラを動かしません。開業済み店舗の明示的な表示は既存の操作を使います。

## 保存と経済

旧LOTS全158件の値と並び、旧48取引物件のID・座標・経済値、旧21道路を保持し、追加物件は末尾へ加えています。保存version 1／envelope 1、既存会社の実績と達成記録、株価の乱数経路を変更しません。

候補の増加で、自動検証の「その時点で条件の良い8物件を選ぶ」方針は別の物件を選ぶようになりました。初回全体検査はこの比較の旧上限に1件失敗しました。資金注入や費用漏れを調べ、旧48候補の同じ経路と、新72候補の支出・実決算・設備簿価を別々に確認しています。テストを通すための経済係数変更は行っていません。詳細は [経済の比較](economy.md) と `completion-v080/economy/adaptive48-72-seed7-01.json` に記録します。
