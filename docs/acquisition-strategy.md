# 100候補から次の一社を選ぶ

友好的買収画面に最大3社の比較を追加しました。一覧の検索・市場・業種を使いながら、候補をページをまたいで比較に追加できます。比較中の各社は独立運営／グループ統合を個別に切り替え、その案の既存の調査・取得確認へ進めます。比較は画面内の一時的な状態で、セーブ形式・取得条件・収益計算には変更を加えていません。調査や取得をまとめて実行する機能ではありません。

## 絞り込みと順序

- 一覧の運営方式を指定し、買収評価額、残り必要現金、稼働利益レンジの下限、業績変動幅、稼働までの期間で並べ替えます。
- 「今すぐ取得可能」は調査済み・信用・上場・選択した方式の即時支払条件を満たす案件です。将来の収支安全性を保証しません。
- 「手元資金内」は調査と引継ぎ準備費を含む残り必要現金が現在の現金内の案件です。信用や上場の条件とは独立しています。
- 現金予算と業績変動幅の上限、未取得／未調査／傘下も絞り込めます。3社を選ぶと追加を止め、入れ替えは個別解除または比較クリアで行います。

## 数字の意味

表示は現在のゲーム内評価額と `getMarketAcquisitionTargets` の運営方式別試算から作ります。実在企業の時価総額・現在株価の取得結果ではありません。

総投資額は「調査費＋買収評価額＋統合費＋準備期間全週の準備費」。支払済みの調査費も総額には含めますが、残り必要現金からは除きます。保有株式は取得時のゲーム内時価で全株充当され、超過分は返金されます。現金予算はこの充当と返金を反映しつつ、返金を受け取る前の調査費を必ず確保する計算です。準備費は将来の支払いのための確保額で、一括引落しではありません。

準備費の確保額は他事業の収入・費用・返済・配当を合算した将来資金繰りではありません。稼働利益レンジは既存モデルの幅で、未調査時は品質未確認の幅を使います。業績変動幅はモデルの基準収益に対する最大幅で、倒産確率ではありません。回収期間や確実な利回りは表示しません。

## 今週と稼働後を分ける

調査済みでその方式の取得条件を満たす場合だけ、現在の状態に `applyAction` を適用した複製を `previewWeek` で評価します。現在からの会社全体の利益差、取得後の今週利益、週末予想現金、取得によって終了する株式配当、借入中の利益不足を表示します。準備中に稼働後の収益を計上することはありません。

3案はそれぞれ同じ現在状態から単独で取得した場合で、3件同時取得の予測ではありません。未調査案件の今週予測は作らず、有料調査を迂回して品質を明かしません。購入済みの会社は比較から除外し、既存の詳細画面で確認できます。

## 検証

`npx vitest run tests/acquisition-comparison.test.ts tests/market-acquisitions.test.ts` は調査済み費用の二重計上防止、即時取得可能と準備費確保の差、株式超過充当時にも必要な先払い調査費、選択方式の資金条件、未調査予測の抑制、配当喪失と借入費用を含むエンジンとの一致、比較による元状態の不変性を検証します。
