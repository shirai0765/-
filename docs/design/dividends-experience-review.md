# 配当・持分の体験レビュー — 次期設計案

営業・成長表示担当による設計批評。コードは変更しない。A「創業者個人資産の任意目標」、B「株主の配当志向が評価・調達へ影響」、C「現在の仕様を明示」の3案を、巨大企業を育てる目的から比較する。A/Bは未実装。数値例は判断を説明する仮定であり、通常キャンペーンで実測した新機能の結果ではない。

結論は**今の製品にはCを維持し、企業経営の新分岐としてはBを検討する。ただしBは条件を満たすまで実装しない。Aは希望する人向けの副目標に限る**。配当した人数やボタンを押した回数を増やすこと自体は目標にしない。全企業取得と街の成長を目指すゲームを、家・生活費・個人消費のゲームへ変えない。

## 現行仕様から言えること

[エンジン](../../src/sim/engine.ts)では、支払配当は上場後の `max(0, 利息後利益) × 配当性向`。会社の現金増減から引くが、営業利益・利息後利益を減らす費用ではない。創業者への現金受取、株主満足、配当による評価上乗せは未実装。会社の成長資金を残す目的なら0%が有利で、率を変えるだけで同等の勝ち筋が増えたとは言えない。

創業者持分は現在、増資による希薄化と20%下限に関わる。50%を下回って指揮権を失う、株主に買収を拒否される、配当しなければ経営権を奪われる、といった統治効果はない。評価額は主に純資産と現在利益から計算され、支払配当は会社現金・純資産を減らす。無配の会社に隠れた株主罰はない。

どの案でも、[キャンペーンの全企業取得・地区目標](../campaign-30h.md)と共通完遂判定を維持する。30時間は体験設計の目標で、配当のための強制週送りを足して埋めない。借入残高がある週の利息後利益が0以下なら、その週に敗北するルールも変えない。

## 同じ状況で、プレイヤーの判断はどう変わるか

### A：会社から取り出した成果を、希望する人だけが追う

例として利息後利益100万円／週、創業者持分80%の上場会社を考える。25%配当なら会社から25万円出て、創業者の個人現金へ20万円、その他株主へ5万円を分配する、という**新しい別勘定**を提案する。0%なら会社に100万円が残り、個人現金への分配はない。25%なら会社に残るのは75万円。

ここで企業評価1億円を前提に25%増資すれば、現行の5%控除後で会社へ2,375万円入り、創業者持分は80%→64%。以後同じ25万円配当なら創業者受取は20万円→16万円となる。

- 全取得を急ぐ人は、配当0%で会社に資金を残し、増資で今の買収を進められる。個人目標は選ばなくてよい。
- 「会社を育てた利益の一部を受け取りたい」人は、会社の投資が遅れる代償を理解して配当する。持分を保つと同額配当から自分が受け取る割合が大きい。
- 同じ人でも買収が目の前なら配当を止め、投資先を保留する局面で取り出す。全取得後にも副目標として続けられる。

この案は「個人への分配」という別の評価軸を足すため、企業成長だけを目的とする場合の0%優位は解決しない。説明を隠して「配当で会社も育つ」と見せるのは不適切。個人資産達成をエンディング・全企業取得の追加条件にしたり、全員へ未達通知を出し続けたりしない。

**採用するなら**個人への分配は一方向に限定する。会社の支払配当を一度減らしたうえで、創業者分をもう一度会社現金から引かない。個人受取を会社へ無料で戻せるようにすると、資金を外へ出す代償が薄れ、個人側の資金注入で借入敗北を救う別ルールまで増える。個人からの再出資・個人所有物の運営・生活費はこの案の範囲外とする。

報酬は「会社を育てて自分も受け取った」と分かる控えめな決算記録で十分。個人の豪邸などを企業成長より大きく演出する方向は今回の目的に合わない。

### B：今の再投資と、今後の資金調達条件を比較する

この案で初めて、会社の目標内で配当が選択候補になり得る。ただし「配当したら株価ボーナス」だけでは理由が弱く、新しい正解ボタンに置き換わる。支払額、営業の安定性、選ぶ資金提供者、実際の調達予定を結ぶ必要がある。

具体的な分岐は次の3つ。

1. **今すぐ利益の出る投資があり、追加増資の予定がない。** 配当のために再投資を遅らせる理由は弱い。0%を保ち、企業成長を選べる。将来の参考株価が高いだけなら、会社現金が増えた成果として祝わない。
2. **安定した既存収益があり、将来の大型買収で外部資金を使う。** 仮に継続的な分配を好む資金提供者から、同じ発行株数で多く調達できる条件が出るなら、累積配当・投資を遅らせる負担と比較して選べる。成長重視の資金提供者には0%再投資方針も適合する必要がある。
3. **保有利益は黒字でも、近い週の現金余力が薄い。** 将来の調達優遇を期待して配当すると、今週の資金が尽きる。支払わない判断が合理的に残る。将来の株価期待を現金と同列に表示しない。

効果の大きさも比べる。企業評価1億円で10%増資なら、現行式の控除後調達は950万円。仮に評価へ5%の上乗せが付いても、同じ発行株数で増える現金は47.5万円にとどまる。累計100万円を配当してこの条件を得るなら、差額だけで支払いを取り戻せない。しかも配当は純資産も減らすため、この例は他条件を固定した楽観的な算術に過ぎない。**5%は採用候補の調整値ではない。** 実装案では配当前後の純資産、調達条件、発行数、手数料、取得を遅らせる影響まで同じ前提で比較する。

Bで見たいのは「大きい配当ほど大きいご褒美」ではなく、「この会社の投資計画には、この資金提供者の条件が合う」という納得である。銀行借入・増資・内部留保の既存比較から離れた、株主満足ゲージ専用作業にはしない。

**採用前に潰す条件**：一週だけ高配当にして即増資・直後に0%へ戻すと得になるか、配当で評価を持ち上げて調達し、調達金を再配当する循環利得がないか。同じ評価上乗せが株価・簿価・借入枠へ無根拠に重複して付かないか。現行には持分20%下限があるため、現行版で無限増資ができるという指摘ではない。将来の評価倍率を入れるなら、既存下限内でも循環のたびに不自然な利益が生まれないかを確認する、という要件。

履歴を条件にするなら、確定した決算・実際の支払を使う。比率を選択した瞬間や未保存の予測で信用実績を作らない。履歴のない旧保存へ過去の無配罰・配当義務を遡及させない。任意に選んだ資金調達条件として期間を持つことと、全プレイヤーへ配当待ちを強制することを区別する。無配でも完遂できる経路を保つ。

### C：現在の限界を正直に伝え、成長へ戻れるようにする

同じ100万円利益なら、0%で会社に100万円、25%で75万円が残る。現在は後者の見返りが個人にも会社にも実装されていないため、巨大企業化を目指すプレイヤーは0%を選びやすい。

表示例は「今は会社の成長資金を残す目的なら配当0%が有利です。配当は会社の現金を減らし、創業者への受取や株主評価の上昇は未実装です」。率を変更できることを、重い経営分岐が完成した証拠にしない。

この案では配当自体の有利不利は変わらない。意味のある選択は、残した会社資金で買収するか、出店・設備・地区開発へ使うか、手元に残すかに置く。創業者持分の表示も、現時点では「次に増資できる余地」に対応させる。多数の同義の評価ゲージを追加しない。

Cは面白さの完成案ではないが、実装されていない効果を説明で補って誤認させるより、現状の判断に役立つ。新しい内容を作るなら、取得した会社や店舗が街にどう現れるか、比較した投資が決算でどうなったかを先に強くする余地がある。

## 3案に共通する表示・敗北条件

| 表示・局面 | プレイヤーへ伝えること | 避ける誤解 |
|---|---|---|
| 支払配当 | 会社から今週出る現金。元本返済と合わせて週末資金へ反映 | 「配当は営業費用なので今週利益も同額減る」 |
| Aの創業者受取 | 個人の現金。会社現金と別勘定、同じ支払の受け手内訳 | 「会社が配当したうえに受取分だけもう一度会社へ費用計上」 |
| Bの評価・調達条件 | 現在の条件／仮定付きの将来見込み／決算後に成立した実績を区別 | 「株価が上がった額がそのまま会社へ入金された」 |
| 持分 | 取得後も残る創業者の割合と、実装済みの効果 | 「50%を割ると実装にない経営権罰が発生する」 |
| 黒字の配当 | 黒字額から分配。配当後の現金不足は別に警告 | 「利益が黒字なら払っても倒産しない」 |
| 借入中の利益0以下 | 配当・個人受取・株価・手元現金では救済しない | 「配当を0へ戻せば営業赤字の借入敗北を回避できる」 |

最後の2行は具体的に分ける。現金10万円、利息後利益100万円、元本返済90万円、その他の現金増減なしなら、配当0%の週末現金は20万円、25%配当なら−5万円。この場合は**黒字なのに現金不足**で敗北する。利息後利益が0以下なら現行の支払配当は元から0で、配当率を下げる操作では**借入中の利益不足**を救えない。Aの個人現金やBの参考評価をどちらの例にも混ぜない。

## 何が確認できれば次へ進めるか

- Aを検討する場合は、個人目標を選ばない人の全取得条件・操作負担を変えず、選んだ人が会社と個人の現金を言い分けられること。全取得に急ぐ人が0%を続けても失敗扱いしない。
- Bを検討する場合は、同じ目標・同じ初期条件でも保有構成と資金計画により、0%再投資と分配を伴う調達のどちらにも妥当な局面を作れること。営業利益を足すだけの倍率や、無配への一律罰で優劣を作らない。
- どちらも、残した／配った金額、諦めた投資、確定した利益・調達をプレイヤーが自分の言葉で説明できるかを見る。配当選択者の人数だけを成功指標にしない。
- 企業取得・都市成長の報酬を主軸に保つ。支払配当の毎週確認、生活用品の購入義務、配当連続週の解除待ちで30時間を埋めない。

Cの説明改善、Aの任意副目標、Bの新しい企業経営モデルは、それぞれ別の仕事。採用判断と新しい保存・予測・経済検証が必要であり、本レビューで実装を承認・開始したものではない。
