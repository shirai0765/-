# 公開REIT決算から見る商業・住宅・オフィスの収益構造

2026年10月6日調査。ゲームの不動産収益モデルに使える**収支項目と指標の意味**を、公式サイトから通常のHTTPSで取得できた3法人の決算で確認した。ソース・数値・PDFページ・期間・取得結果・SHA-256は [metadata](property-economics-metadata.json) に保存した。コード・保存形式・経済値は変更していない。

賃料収入から管理・税・修繕などを引き、さらに会社費用・金利・設備投資・元本返済を区別する構造には根拠がある。一方、この3例からゲームの物件価格、週次利回り、鉄道開発による需要上昇率を決めることはできない。**現実の半年の決算を26で割り、本作の1週と同じ現実時間の収益だとは扱わない。**

## 法人全体の半年収支

単位は**百万円**。営業収益は各短信表紙の百万円未満切捨て値。賃貸内訳は短信の千円表示を百万円へ変換しているため小数3桁。単位変換であり年換算ではない。

| 指標 | JMF・2026年2月期 | ADR・2026年7月期 | NBF・2026年6月期 |
| --- | ---: | ---: | ---: |
| 営業収益（法人） | 52,075 | 20,560 | 53,858 |
| 不動産賃貸事業収益 | 44,941.566 | 19,547.259 | 48,665.348 |
| 不動産賃貸事業費用（減価償却を含む） | 19,988.189 | 8,448.397 | 24,890.159 |
| うち減価償却費 | 5,660.991 | 3,757.263 | 8,033.826 |
| 上記から再計算：収益−費用＋減価償却費 | 30,614.368 | 14,856.125 | 31,809.015 |
| 説明資料で公表されたNOI | 31,107（受取配当金込み） | 14,856 | 31,809 |

出典：営業収益は各短信PDF p.1。賃貸内訳はJMF短信p.25、ADR短信p.25（説明資料p.69にも同じ内訳）、NBF短信p.18。公表NOIはJMF説明資料p.40、ADR説明資料p.11、NBF説明資料p.5。

再計算行は本調査の算術であり、各社のNOI定義を統一した新しい会計指標ではない。減価償却以外の非現金項目を一律に戻しておらず、元資料の切捨てで千円程度の差も生じる。JMF説明資料のNOIには脚注で受取配当金を含むとある。短信p.13の受取配当金492.987百万円を再計算値へ足すと31,107.355百万円となり、公表31,107百万円との違いを説明できる。これを商業物件だけの家賃利益とは呼ばない。

営業収益と家賃を混同してはいけない。たとえばNBF説明資料p.5は、営業収益53,858百万円に不動産売却益5,192百万円が含まれることを示す。ADRも短信上、営業収益には売却益を含む。JMFでは売却益と受取配当金も含む。売却益を毎期の賃料成長として外挿しない。

費用構成も用途別に読む。JMFには建物管理委託費・水道光熱費・公租公課・修繕費・支払賃料等、ADRには管理業務等委託費用・原状回復を含む修繕費等、NBFには外注委託費・公租公課・修繕費等がある。法人の資産運用報酬・一般管理費・借入利息は、物件賃貸費用と別の段階にある。

ADR説明資料p.20には専有部リノベーションで空室期間が増える説明がある。これは「改修費を払い終えた瞬間から、空室も工事停止もなく増収する」という単純化を見直す材料になる。ただし同社の工事期間や影響幅を、そのまま全物件のゲーム設定にはしない。

NOIは自由に使える現金と同じではない。元本返済、資本的支出、会社全体の管理費や利息、入出金時期が別にある。減価償却を戻したからといって建物更新が無料になるわけでもない。NBF説明資料p.33にはNOI・FFO・AFFO・資本的支出が別々に掲載されており、手残りの階層を区別する根拠になる。

## 都市商業施設の個別例：Gビル神宮前06

JMFの法人全体を渋谷の1物件へ縮小して見せることを避けるため、資料にある個別行を確認した。説明資料p.41では用途は商業（ハイストリート）、所在地は東京都渋谷区。物件番号10016で照合した。

| 項目 | 値 | 時点・範囲・出典 |
| --- | ---: | --- |
| 取得価格 | 2,360百万円 | 当該物件の過去の取得価格。説明資料p.41 |
| 賃貸事業収入 | 58百万円 | 2025年9月〜2026年2月の当該物件収入。短信p.48 |
| テナント数・稼働率 | 4件・100.0% | 2026年2月期末。短信p.48 |
| 鑑定評価額 | 3,290百万円 | 2026年2月の期末鑑定。説明資料p.48 |
| 直接還元法の還元利回り | 2.9% | 同期の鑑定パラメーター。説明資料p.48 |

短信p.48はページ画像でも、当期列・百万円の単位・期末稼働率と期間収入の区別を確認した。同ページには別物件の収入が非開示となる行もある。非開示をゼロや推定の実績値で埋めない。

58百万円はテナントが払う賃料等の収入であり、テナント自身の売上でも、物件のNOIでもない。ここで確認した個別行には費用・NOIがなく、**この物件の実績NOIは未採録**。2.9%は鑑定の還元利回りであり、取得価格に掛けて実際の入金を作る定数にはできない。100%稼働が永続する保証もない。

今回ADR・NBFは法人・ポートフォリオの収支を採録し、特定住宅棟・特定オフィス棟の収支セットまでは採録していない。3例すべてを「同じ規模の1棟比較」と表示しない。個別物件向け係数が必要なら、同じ期間の物件費用・NOI・賃貸可能面積・取得持分を揃える追加調査が要る。

## ゲームへ持ち込むなら、まず収支の因果を使う

| 根拠にできる構造 | 設計で分けたいもの | この資料だけでは決められないもの |
| --- | --- | --- |
| 賃貸収益と面積稼働 | 満室時の契約賃料、空室、賃料改定、用途 | 新駅開業で需要が何%増えるか、全地区一律の賃料上昇 |
| 管理・税・修繕・更新 | 経常費用、修繕費、資本的支出、工事による空室 | すべての物件で売上の一定率となる維持費 |
| 物件収益と法人費用 | 物件NOI、会社経費、利息、元本返済後の現金 | NOI黒字だけで借入返済が安全という判定 |
| 取得価格・簿価・鑑定 | 初期資金、未換金の評価、売却時の実現損益 | 鑑定評価がその週の現金になる仕組み |
| 用途と契約の違い | 商業テナント・住宅・オフィスの調整や改修 | REIT法人合計を街の小さな自用店舗へ同率適用 |

本作の「借入中に利息後利益が0以下ならその週で敗北」はゲームの明示ルールとして維持する。このREIT資料は、現実の借入がその条件で即倒産するという証拠ではない。またREITの分配方針・税務上の仕組みを、一般事業会社の配当強制の根拠へ流用しない。

今後ゲームへ校正する場合も、現実資料から得た比率・因果の参考部分と、30時間の企業取得体験に合わせて調整する時間・価格・報酬を別に示す。「実企業の公開資料を参考にしたモデル」と「実企業そのものを週単位で再現したモデル」は異なる。今回の成果は前者の設計材料であり、校正・実装・到達性試験を済ませたものではない。
