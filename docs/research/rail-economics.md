# 鉄道・沿線事業の公開決算とゲームへの適用範囲

調査日: 2026-10-06。対象は東急株式会社と小田急電鉄株式会社の **2026年3月期通期実績（2025-04-01〜2026-03-31）**。公式IRページから通常HTTPSで取得した決算短信・補足資料の該当表と注記を読んだ。以下は実在企業の観測値と、本作への設計上の解釈を分けた研究であり、0.4.1の係数やコードを変更したものではない。

結論は、鉄道グループを「乗客数×利益」の一項に置き換えないこと、営業利益・営業CF・設備投資実施額・取得時の現金支出を別々に扱うことである。連結利益を買収対象の基礎利益として採用した上に、その企業が既に得ている運賃や賃料を再加算してはならない。

## セグメントの営業収益と営業利益

すべて **百万円、通期実績**。外部収益は外部顧客への営業収益、部門収益は内部取引・振替を含む計、部門利益は営業利益ベースのセグメント利益である。どちらの会社も百万円未満切捨てのため、表示値を足すと公表の計と端数差が出ることがある。

| 会社・セグメント | 外部収益 | 部門収益 | 部門利益 |
|---|---:|---:|---:|
| 東急・交通 | 223,130 | 226,946 | 27,341 |
| 東急・不動産 | 212,736 | 262,995 | 43,595 |
| 東急・生活サービス | 511,523 | 533,271 | 21,868 |
| 東急・ホテル・リゾート | 138,789 | 139,346 | 9,710 |
| 小田急・交通 | 178,787 | 181,261 | 29,517 |
| 小田急・不動産 | 84,844 | 96,226 | 15,473 |
| 小田急・生活サービス | 155,100 | 158,606 | 7,658 |

出典: T1 PDF17（印刷15）、O1 PDF18（印刷16）。東急の部門収益計1,162,559から内部取引76,380を消去した連結営業収益は1,086,179。小田急は436,094から17,362を消去し418,732となる。部門利益も消去調整を経て連結営業利益に接続するため、部門合計と連結を二重に足さない。

交通部門は純粋な鉄道業だけではない。東急は鉄軌道・バス・空港運営、小田急は鉄道・バス・タクシー・航路・索道等を含む。不動産は賃貸だけでなく販売等も含む。東急の生活サービスには小売・商業施設・ケーブルテレビ・広告・映像等が含まれ、ホテルは別部門。小田急の生活サービスは百貨店・小売・ホテル・飲食等を含む。両社の同じ部門名をそのまま同業の利益率比較にしない（T1 PDF15、O1 PDF17）。

鉄道に近い内訳として、T2 PDF32の「東急電鉄等」は営業収益1,660億円・営業利益228億円、O2 PDF8の「鉄道業」は営業収益132,621百万円・営業利益23,350百万円だった。対象範囲と精度が違うので、これも同一定義の比較値とはしない。東急資料では輸送人員が前年比3.1%増でも、交通部門の営業利益は5.7%減。輸送人員だけから利益が同率で伸びる係数は得られない。

## 営業CFと設備投資は別の数値

次表も **百万円、同じ通期の連結実績**。CF支出は負号で記した。

| 指標 | 東急 | 小田急 |
|---|---:|---:|
| 連結営業利益 | 103,193 | 52,659 |
| 営業活動CF | 127,747 | 59,915 |
| 投資活動CF | −174,984 | −84,274 |
| 財務活動CF | 68,386 | 29,270 |
| 有形・無形固定資産の増加額 | 179,996 | 81,385 |
| CF計算書の固定資産取得支出 | −159,324（固定資産） | −84,618（有形固定資産） |

出典: 営業利益は両短信PDF1。CFはT1 PDF13〜14、O1 PDF14〜15。資産増加額はT1 PDF17、O1 PDF18。小田急の資産増加額には長期前払費用が含まれる。CFの取得支出は表中括弧の原資料項目名どおりで、両社同一範囲の「capex」へ機械的に統一しない。

東急概況T2 PDF39は設備投資を実施ベースとして示し、期末未払金等を考慮するCF計算書の数値と異なることを明記する。PDF38の現金支出ベース約1,593億円と、PDF39の実施ベース約1,799億円を同じ金額として扱えない。小田急O2 PDF3の設備投資額81,385百万円は短信の資産増加額と一致するが、CF取得支出84,618百万円とは一致しない。

営業CFには非資金費用の調整、債権・棚卸資産・債務の増減、税や利息の支払等がある。利益そのものでも、投資後に自由に配れる現金でもない。投資CFには固定資産取得のほか売却・有価証券等が含まれる。設備投資の全額を営業利益から引く処理と、費用化された減価償却を引く処理も別である。例えば東急T1のCF調整の減価償却費88,548百万円と、セグメント表調整後の88,544百万円は掲載値自体が異なるため、無断で一方へ揃えない。

なおT2 PDF19の3か年投資・CF計画は説明用に一部組替済みで、CF計算書とは異なるとの注記がある。本研究はそれを当年の資金収支や恒常収益として採用していない。安全更新・維持投資と成長投資の通期内訳も今回の読取だけでは確定していない。

## 本作への適用と重複を避ける境界

現行の [engine.ts](../../src/sim/engine.ts) は、既存8社の買収後利益を `weeklyProfit` に景況・個別変動を掛けて計上し、グループ運営費を別途引く。ここに駅利用者由来の運賃利益や、同じ買収会社の保有不動産賃料をもう一度足す根拠は、この連結IRからは得られない。将来、内訳をモデル化するなら「既存の一括利益を内訳へ置き換える」か「新規投資による基準比の純増だけを足す」かを先に決める必要がある。

現行の [沿線共同開発](../rail-projects.md) は別の任意投資であり、地区内の自社カフェ需要または直接保有する外部賃貸物件の収入を改善する。買収鉄道会社の `weeklyProfit` 自体は増やさない。所有区分・対象物件が違うため同じ人流が複数事業へ影響すること自体を二重計上とは呼ばないが、既存基礎利益に含めた同じ取引を再計上することは避ける。自用店舗には外部賃料が生まれず、カフェも処理能力上限に達すると需要増が利益増になるとは限らない。この効果の大きさや工期が現実に妥当かは、今回の集計資料では検証できない。

設備投資を導入する場合も、着工時の現金支出・資産評価・工事中と稼働後の維持費・減価償却を分けて設計する。既存 `weeklyProfit` が何を控除済みか不明なまま、実在企業の維持費率や設備投資率を追加すると二重控除となる。現在の共同開発は着工費を一度だけ現金から払い、維持費を毎週利益へ反映するゲーム用モデルであり、IRに合わせた減価償却会計ではない。

本作の借入中 `netProfit <= 0` 敗北、現預金不足、現在週の予測と確定決算の一致は維持する。実在企業の投資CFが負であることを、本作の営業赤字と同一視しない。逆に「現実では成長投資が許されるから」という理由で敗北条件を緩めたり、予測に出ない将来の維持費を突然課したりしない。鉄道取得・共同開発に新しい必須待機や必須ゴールを追加する提案でもない。

## 次の改善議論に使えること・使えないこと

今回の一次資料が支えるのは、事業範囲の区別、消去取引、利益と資金収支の区別である。実在企業の年利益を52で割ってゲームの週利益へ写すこと、セグメント資産を買収価格とみなすこと、交通増から地区賃料への因果倍率を求めることは支えない。買収対象は架空企業であり、現在の価格・利益・工期はゲーム設計値のまま扱う。

カフェIR・REIT IR・店舗設定実験との統合時には、「客数や稼働率が増える→何の売上が増える→追加費用と能力上限を経てどれだけ営業利益が残る→投資支出後に現金が残る」を各対象で説明できるかを先に確認する。現時点では他研究の結果をこの文書で検証済みとはせず、具体係数の変更は別提案・別検証とする。資料読取は人間の初回15分や30時間プレイの検証にも代わらない。
