# 0.4.8：会社に合わせた遊び方と保存の復旧

0.4.8公開・検証済みの記録です。全体テスト・ビルド、目印と保存復旧・ガイドの実ブラウザー検査、Web/Windows梱包、公開HTTPと公開ガイドの検査は成功しました。

## 会社の今の状態から確認する

遊び方は、経営終了→確定報告あり→店舗なし→営業中の順で会社の状態を判断します。全店を閉じても報告が残っている会社には、直近の結果を読む案内を表示します。

| 会社の状態 | 任意の移動先 |
| --- | --- |
| 経営終了 | 設定・保存を開く |
| 確定報告あり | 営業結果を見る |
| 店舗なし・報告なし | 出店場所を見る |
| 営業中・報告なし | 店舗を経営する |

各ボタンは説明を閉じて既存の画面へ移動します。「説明を閉じる」だけでも続けられます。出店・物件・店長・固定価格・黒字を必須手順にしません。

旧global v1読了設定を維持し、手動の「経営→遊び方」を残します。新しい会社や進行段階ごとの自動再表示は追加しません。見る・閉じる・移動だけで、週・現金・所有や会社の保存を変えません。読了設定は従来どおり会社保存とは別です。

## 保存を読み込めないとき

起動時の形式・チェックサム・会社データ検証で現在のセーブの破損を検出した場合、開始画面に「現在のセーブを読み取れません」と表示します。保存履歴からの復元、保存ファイルの読込、新しい会社の設立を選べます。ファイル読込と新会社は置換を確認してから保存します。使える履歴がない場合は、その旨を表示します。

通常の自動保存では破損した保存を置き換えません。履歴を開く、案内を閉じる、置換を取り消すだけでは変更せず、ファイル検証や書込が失敗しても元の保存を残します。別タブが先に保存を更新した場合は置換を拒否します。保存領域や暗号機能を使用できないエラーは、破損として扱いません。全データの回復を保証する案内ではありません。

保存・読込・週終了の処理中は同期的な操作ロックで追加実行を止め、開始画面にも処理中の状態を表示します。経済係数・経営終了条件・保存履歴の直近12件の保持方針は維持します。

## 自社の施設を街で見る

ゲーム街の「自社の施設」表示では、自社の店舗と保有物件の目印だけを表示します。借りた土地にある自社店舗も含みます。店舗近景では目印を隠し、街全体へ戻ると選んでいた表示へ戻ります。非表示の目印はクリック対象にもなりません。出店候補は「物件を探す」の全32区画一覧から引き続き選べます。表示の切替は会社の現金・所有・週を変えません。
