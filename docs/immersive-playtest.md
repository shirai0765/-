## 0.4.5当時の全面街UIと週末の営業結果

0.4.5の実装・検証記録です。最終全体テスト・ビルド・統合ブラウザー・本番CSP・梱包検証を終え、0.4.5を公開しました。局所検証、描画を置換したDOM検証、実GPUの確認範囲を分けて記録します。人間の初回プレイの合格とは扱いません。

## 街から始める操作

街を画面全体に表示し、常設の左右パネル、上部の集計列、下部のダッシュボードを取り除きました。現金、経営メニュー、地図、週終了などの小さな操作を重ねます。ゲーム街の32区画は青の出店候補・緑の営業店舗・紫の保有物件の目印で示し、施設を選ぶとブラウザー標準のdialogで詳細を開きます。全32区画の一覧は任意に開ける入口として残し、実測街の表示設定も開いたときだけ表示します。実測街の対応地点は従来どおり4地点です。

最短の自然な入口は「会社を設立 → 街の出店目印を選ぶ → 形態と支払額を確認して開業 → 週を終了 → 最初の営業結果」です。初開業後は詳細を閉じ、開業したカフェの外観へ移ります。開業通知は営業結果や保存完了の通知とは区別します。長いチュートリアルを読まなくても、この経路を選べることを統合検証の対象にしています。

出店ダイアログは3形態の選択、開業費、支払後現金、利益の見込み幅、開業ボタンを先に表示します。「初期設定・比較の詳しい内訳」は初期状態で閉じ、基準値との差や既存店への影響を中へ移しました。資金不足と借入中の利益・週末現金の危険は開業ボタンの前に残します。利益の見込みが0をまたぐ場合と、上限でも終了条件に当たる場合を区別します。

## 見込みと実績

営業前は中立条件の見込みと保守的な上下限を使い、当週の実現条件を先読みしません。通常の週終了確認では見込みを閉じた詳細へ置き、危険がある場合は注意を常時表示します。新しい利益・客数は週を確定した後の実績として示します。範囲は確率や信頼区間ではありません。

店舗の客足・運営能力などに週次変動を加えるため、これは表示だけの更新ではありません。借入が残る決算の利益0以下と、週末現金不足による終了条件は維持します。連続営業は見込みの下限に危険があれば決算前に止まります。

保存形式と過去の実績は保持します。旧会社も次週から新方式を使うため、旧版と将来の数値が一致するとは保証しません。seed・週・地点等に基づく結果は、通常の再読込や設定・店名の往復では引き直しません。クライアント内の値を技術的に秘匿する仕組みではありません。
